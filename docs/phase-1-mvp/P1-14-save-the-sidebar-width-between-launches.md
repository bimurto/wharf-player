# P1-14: Save the sidebar width between launches

**Status:** Built, needs manual check  
**Requirements:** P1-B2  
**Depends on:** P1-10  

## What

Remember how wide the user made the sidebar.

## Acceptance criteria

- [ ] Width saved when changed and restored on launch
- [ ] Limited to 320 pt minimum and 75% of the window
- [ ] Window resizing clamps without losing the saved value
