# P1-22: Subtitle sync offset

**Status:** Built, needs manual check  
**Requirements:** P1-T4  
**Depends on:** P1-17  

## What

Delay or advance subtitles by up to 5 seconds.

## Acceptance criteria

- [ ] Slider from -5 s to +5 s with 0.5 s step buttons; a positive value delays captions
- [ ] Sets `sub-delay`; value shown beside the slider
- [ ] Resets to 0 when a new video starts
