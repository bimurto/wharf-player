To begin, add a server. Give it a label, host, port, user name and a password or key file. The password goes into the macOS Keychain, never into a file, a URL or your history. Test Connection logs in and tells you what really went wrong.

The first time you connect, Wharf shows the server’s fingerprint and asks before it trusts it. A key that changes later is refused. Wharf keeps its own list of known hosts and never touches the one in your home folder.

Before you install

What do I need to run it?

A Mac with Apple silicon on macOS 26 or later, and a server you can reach over SFTP: a seedbox, a NAS or a VPS. Any server that speaks SSH will do.

Does Wharf download the file first?

No. A small proxy on your Mac fetches only the bytes the player asks for, with 32 reads in flight so the picture keeps up. Seeking jumps straight to the right place in the file, and nothing is written to disk.

Where does my password go?

Into the macOS Keychain. It is never written to profile files, URLs, recents or logs. Deleting a server removes its password or key passphrase from the Keychain too.

Why does macOS warn me when I open it?

Wharf is ad-hoc signed and not notarised yet. Right-click the app and choose Open, or run this once in Terminal:

xattr -dr com.apple.quarantine /Applications/Wharf.app
Which files does it play?

Anything mpv plays. The Library marks MKV, MP4, M4V, MOV, AVI, WebM, TS, M2TS, MTS, WMV, FLV, MPEG, OGV and 3GP as videos, and finds SRT, VTT, ASS and SSA subtitles beside them.

Is it free?

Yes. Wharf is free software under the GNU General Public License, version 3 or later. It bundles unmodified builds of mpv, FFmpeg and their libraries under their own licences, listed in the third-party notices with a written source offer.
